# Security Policy

## Supported versions

This is an internal monorepo; only the `stage` branch is actively maintained.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately by email to **bugs@playerberry.com** (or via
GitHub's private "Report a vulnerability" advisory flow).

Include, where possible:

- A description of the vulnerability and its impact
- Steps to reproduce or a proof of concept
- Affected package(s) and version(s)

You can expect an acknowledgement within a few business days. Please give us a
reasonable window to investigate and release a fix before any public disclosure.
