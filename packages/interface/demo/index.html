April Interface

A CSS framework authored in Less: prefixed components, stacked variant words, shared colour roles, light and dark themes. This demo is built with the framework itself.

Colour roles

Seven roles shared by every component. Hover, active, soft and contrast values are derived at build time.

primary--ai-primary
secondary--ai-secondary
success--ai-success
danger--ai-danger
info--ai-info
warn--ai-warn
neutral--ai-neutral

Surfaces

bg--ai-bg
raised--ai-bg-raised
sunken--ai-bg-sunken
text--ai-text
text secondary--ai-text-secondary

Conventions

  • Component classes carry the ai- prefix; variants are short words stacked after it: ai-button ghost primary lg pill.
  • Shape words mean the same everywhere: square, soft, rounded, pill. Sizes: sm, md, lg.
  • Theme follows the system; the toggle in the top bar pins light or dark and remembers it.
